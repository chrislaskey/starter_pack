# Public pages: suggestions

Not built, to discuss first:

- `/` redirecting to `/home` for a browser with the `token` cookie.
- Sign-out on the web landing on the public home page rather than the
  sign-in page.
- `robots.txt`, a sitemap, and Open Graph tags for link previews.
- A pricing page, once purchasing exists in `accounts`.
- Longer content (a blog, a changelog, documentation) written in
  Markdown. Worth a common static site library then, not more of our
  own build plugin.
- Cache headers for the public pages.
